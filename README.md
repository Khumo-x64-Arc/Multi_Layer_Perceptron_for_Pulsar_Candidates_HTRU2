# COS 711 MLP Assignment 1 

## Project Specifications 
For this assignment, you must build and systematically investigate a multilayer perceptron (MLP)
applied to a classification or regression task of your choosing (see Section 2.1). The assignment has
two parts: a core investigation into MLP fundamentals (Section 2.2), and a focused research investi
gation into the relationship between learning rate warmup and a model’s robustness to compression
(Section 2.3).
